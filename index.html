FAQ

下载前想清楚的几件事

和 Listary / PowerToys Run 有什么不同？

它们擅长「搜一个就开」。启程典擅长「一组一起开」——场景收纳 + 批量启动 + 间隔，专治开机手忙脚乱。

会不会把我的数据传到云上？

场景与启动项保存在本机。授权校验为本地逻辑；检查更新才需要联网。

为什么仓库里没有源代码？

本仓库只发布 Windows 安装包与产品说明，不开放源码。请从 Releases 下载安装，不要 clone 期望得到工程。
