FAQ

下载前想清楚的几件事

和 Listary / PowerToys Run 有什么不同？

它们擅长「搜一个就开」。启程典擅长「一组一起开」——先收进场景（典 / Dock），再一键启程（启 / Rise）。专治开机手忙脚乱。

怎么买？多少钱？

应用内复制机器码 → 加客服微信发「姓名 + 联系方式 + 机器码」。价目：月卡 ¥9.9 · 季卡 ¥24.9 · 年卡 ¥79 · 永久 ¥128 起（详见 价格区）。

场景配丢了怎么办？有没有备份？

有。打开或关闭软件时会按设定频率自动备份（默认每周），可在设置里管理与恢复；也支持手动备份到指定位置，以及场景 JSON 导入导出。

会不会把我的数据传到云上？

场景与启动项保存在本机。授权校验为本地逻辑；检查更新才需要联网。

为什么仓库里没有源代码？

本仓库只发布 Windows 安装包与产品说明，不开放源码。请从官网直链或 Releases 下载安装，不要 clone 期望得到工程。

免费能用多久？过期会丢数据吗？

未激活可持续用免费额度（1 场景 / 每场景 3 启动项）。过期后保留最早场景与最早 3 项，其余冻结但不删除；续费后解冻。
