## 它解决什么

每天开机都在重复同一件事：微信、浏览器、文档、直播工具、IDE……一个个双击，还要等前一个起来。少则五六个，多则十几个。桌面图标越堆越乱，换个工作状态（直播 / 上班 / 写代码）又要点一遍。

**启程典不是又一个「搜一下就开」的启动器。** Listary、PowerToys Run 擅长找一个东西；启程典擅长把同一场景里的多项一起开——先收进场景（典 / Dock），再一键启程（启 / Rise）。专治开机手忙脚乱。

装上之后，桌面可以只留这一个图标。直播开播、上班开工、写代码冲刺，各配一套工具链，一点即开。

## 30 秒怎么用

1. **建场景**  
   直播、上班、写代码……一类工作一个场景。重要的右键置顶钉在首页；多了用一层分组收成文件夹，点进去看，返回即回首页。删组不丢场景。

2. **收进去**  
   应用、文件、文件夹、网址都能放。可「+ 添加 / 批量添加」，也可从资源管理器直接拖入（可多选）。可设启动间隔，避免十几个程序同时挤爆系统。脚本启动项（`.vbs` / `.vbe` / `.wsf`）也能开。

3. **一点，全部起来**  
   按钮或热键启动该场景内所有已启用项。下次还要从同一位置开工，可以给启动项记下窗口位置。文件搬家找不到了，看板 / 热键 / 搜索 / 编辑器里都能弹出定位，不用整条删掉重加。

## 功能一览

### 场景工作台

- **一键启动**：点场景，按顺序拉起该场景内已启用项；间隔可调，前一个起来再开下一个。
- **场景置顶**：重要场景钉在首页最上，哪种排序都优先；进了分组也能从首页直接启动。
- **一层分组**：文件夹式收纳，钻入看场景卡，返回即首页；删组只拆夹，场景还在。
- **常用排序**：场景详情可按启动次数排「常用」，越用越顺手。
- **搜索合一**：顶栏搜索与 Ctrl+K 同一弹窗。点结果进场景细看；回车 / 🚀 仍直接启动，不绕路。
- **按场景导出**：一张场景卡就能单独导出这一条；全库导出叫「导出全部场景」，不怕导错一整包。

### 往里装填

- **拖入添加**：资源管理器多选拖进场景详情即可，不必一条条填路径。
- **整理桌面**：扫桌面勾选进场景，默认挪到「文档\启程典\桌面备份」，不默认删除——桌面终于可以干净。
- **发现本机软件**：从开始菜单 / 桌面建场景；可加自定义扫描文件夹（便携盘 / Scoop 等），拒绝全盘乱扫。
- **从其他收纳导入**：可从 Rolan / Maye 一类工具往里迁，减少重装后的手工搬家。
- **脚本也能开工**：`.vbs` / `.vbe` / `.wsf` 当作启动项，点得开。

### 开工细节

- **路径自愈**：目标文件找不到时，看板、热键、搜索、编辑器都会弹出定位，不再只在一键启动里能修。
- **窗口位置记忆**：启动项可记下窗口位置，下次还原；可清除，也可跳过这一次。多显示器几何一起记。
- **启动后隐藏**：可选择启动后把主窗口藏起来，桌面只留你真正要干活的那些窗。默认不藏，随你。
- **快捷启动**：设置里单独配名称、路径、全局热键，一键打开单个应用 / 文件 / 网址。不占场景额度，也不跟场景热键、显隐热键打架（占用会提示）。
- **系统组件**：独立面板单击执行关机 / 重启 / 锁屏、此电脑、控制面板等。不进场景、不设热键，不占免费额度。

### 观感与数据

- **16 款主题**：免费 6 款 + 会员 10 款（墨黑 / 霜蓝 / 玫瑰金 / 青瓷等），换肤不换习惯。
- **本地自动备份**：按设定频率备份（默认每周），设置里可管理、恢复；也支持备份到你指定的非系统盘。桌面备份 ≠ 重装保命，重要库请另存一份。
